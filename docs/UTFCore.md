# UTF Core Repo

The [UTF Core repo](https://stash.silabs.com/projects/UTF/repos/utf_core/browse) 
is an essential UTF component, containing the `utf` python package which includes the common
fixtures, interfaces, and utilities of the UTF framework.

API documentation for the `utf` package is available [here](https://nexus.silabs.net/repository/utf/core-api-docs/master/autoapi/index.html).
