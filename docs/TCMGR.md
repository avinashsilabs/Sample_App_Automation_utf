# Toolchain Manager

[Toolchain Manager](https://stash.silabs.com/projects/TOOLCHAIN_INTERNAL/repos/tcmgr/browse) is included as a submodule of the application template in order to assist in the initial setup of the UTF application workspace.

Toolchain Manager includes an embedded version of python that can optionally serve as the base interpreter for the virtual python environment needed to launch UTF tests.

See [Workspace Setup](./WorkspaceSetup.md) for further info on how toolchain manager is used during workspace setup.
